1 · The Problem

Malaysia wants to recycle more, but it still ends up in landfill

~38,000 t/day
solid waste generated daily, about 82% still goes to landfill
~30%
national recycling rate, below the 40%-by-2025 target
~40%
of landfilled waste is actually recyclable, value lost
In a township, it stalls for three reasons:
😐
No incentiveEffort, no reward, so resident turnout stays low.
💸
Seen as a costRecycling is a cost centre, so programmes get cut.
🚛
Blind collectionTrucks run fixed routes to half-empty bins, wasting fuel.
Sources: UNIDO (2025) · Asia News Network (2026) · KPKT Circular Economy Blueprint 2025-2035. Figures indicative.GreenLoop · Team Synkosys
